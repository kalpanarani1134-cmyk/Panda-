PANDA BIRTHDAY WEBSITE 🐼🌻

1. Keep the folder structure exactly as it is.
2. Open index.html in a browser to preview it.
3. For a phone, upload the whole folder to any static website host, or open index.html locally.
4. Photos are in assets/photo-*.jpeg and the video is assets/memory-video.mp4.
5. To replace media, keep the same filenames.

The design is mobile-first, uses full-screen slides, separate photo/video sections, and sunflower/tulip decoration.
